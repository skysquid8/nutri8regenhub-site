Nutri8 Regen Nutrition Hub — website files
==========================================

CONTENTS
  index.html      the page
  images/         all five photographs and the logo

HOW TO PUBLISH
  Upload index.html and the whole images/ folder to your web host, keeping
  them side by side (index.html at the top level, images/ next to it).

HOW TO UPDATE
  Text:   open index.html in any text editor and edit the words between the tags.
  Photo:  drop the new file into images/ using the SAME filename, and it swaps
          everywhere. Or change the filename inside index.html to match.

NOTE

  needs an internet connection to show them; it falls back to Georgia and the
  system sans if blocked.
