# For Claude Designer

This repo is connected to Netlify and auto-deploys to **nutri8regenhub.com**.

## How to update the site

1. Clone this repo: `git clone https://github.com/skysquid8/nutri8regenhub-site.git`
2. Make your changes to `index.html` and/or files in `images/`
3. Commit: `git add . && git commit -m "Update site"`
4. Push: `git push origin main`

Every push to `main` automatically deploys to production at https://nutri8regenhub.com
